Endpoints

GET/api/v1/news

Unified, deduplicated feed across all sources (or one), newest first.

ParamValuesNotes
sourceall (default) · mapnews · map-portal · map-sport · hibasportmapnews = daily portal; map-portal = institutional site; map-sport = sports (FR); hibasport = Arabic sports (Hiba family, open WP API)
langen · fr · ar · esmap-sport only publishes FR; others fall back gracefully
sectionmapnews sectionse.g. politique, economie, monde, general, sport, culture — see /sections
categoryWP category slugonly for map-portal/map-sport — see /categories
page, limitintegerslimit ≤ 50
GET/api/v1/news/article

Full article by URL (works for any article on the three sources). Returns title, lead, full HTML + plain-text body, image, city, categories, dates.

url=<URL-encoded article URL> (required)

GET/api/v1/search

Cross-source search. WordPress sources use their native search; mapnews scans its live section feeds.

q=text   lang=en|fr|ar   source=all|mapnews|map-portal|map-sport|hibasport   limit=n

GET/api/v1/categories

Category taxonomy per source (WordPress categories; mapnews sections).

source=all|mapnews|map-portal|map-sport|hibasport   lang=…

GET/api/v1/sections

mapnews sections auto-discovered from the portal navigation, with their RSS URLs.

lang=en|fr|ar

GET/api/v1/news/archive

Deep archive (URL + last-modified) from the mapnews sitemap — tens of thousands of articles.

lang=en|fr|ar   page=n

GET/api/v1/health

Upstream status per source + cache stats.

POST/api/v1/ai/summarize

Generative AI summary of any article. Body: { "url": "<article url>", "lang": "en|fr|ar|es" }. Returns { engine, tldr, bullets } — engine is generative when AI_API_KEY is configured (any OpenAI-compatible provider via AI_BASE_URL/AI_MODEL), otherwise extractive (on-device TextRank-lite, always available).

POST/api/v1/admin/cache/clear

Empty the response cache. GET /api/v1/admin/cache shows its size.

Use it from your website

// JavaScript (browser or Node)
const res = await fetch("http://localhost:3000/api/v1/news?source=all&lang=en&limit=12");
const { items } = await res.json();

// list item  →  render card        full body →  fetch detail
items.map(it => `<a href="/news/${it.id}">${it.title}</a>`);
const full = await (await fetch(
  `/api/v1/news/article?url=${encodeURIComponent(items[0].url)}`
)).json();

Notes

TopicDetail
CachingLists 5 min · articles 30 min · taxonomy 1 h · sections 6 h. Upstream failures serve stale data (cacheState in logs).
Politenessmapnews.ma robots.txt Crawl-delay (10 s) is enforced between upstream requests; map-sport/map-portal max 1 req / 1.5 s.
AuthOpen by default. Set API_KEY to require an x-api-key header. Set CORS_ORIGIN to lock browser access to your domain.
Rate limit300 req/min per IP (configurable via RATE_LIMIT_PER_MINUTE).
AttributionContent belongs to MAP (Maghreb Arabe Presse). Display source + link back to the original article.
Sourcesmapnews, map-portal, map-sport, and hibasport (Arabic sports portal — Hiba family, open WordPress REST, ~108k posts, AR only). The HibaPress general portal (hibapress.com) is behind Cloudflare bot protection and is intentionally not accessed.

MAP News API v1 — not affiliated with MAP. Data fetched from public RSS/REST endpoints of mapnews.ma, www.map.ma and mapsport.ma.
